# PathPilot AI

PathPilot AI is a multilingual career guidance tool designed for students who are unsure about their first job role.

Users enter their course, existing skills, interests, preferred location and available preparation time. The system compares this profile with entry-level career paths and returns three suitable roles with clear reasons, missing skills and a personalised 30-day action plan.

## Features

- Three ranked career recommendations
- Transparent compatibility scores
- Skill-gap identification
- Personalised 30-day preparation plan
- English and Hinglish explanations
- Mobile-friendly interface
- Optional IBM watsonx Assistant integration
- No account or personal-data storage required

## How It Works

PathPilot represents the student’s answers and each career role as a set of features. A weighted similarity model compares skills, interests and career priorities to rank the most relevant roles.

The matching logic is visible to the user instead of presenting an unexplained AI-generated answer.

The current prototype includes career paths such as:

- Junior Data Analyst
- Reporting Analyst
- Business Analyst
- Junior Python Developer
- Machine Learning Intern
- Operations Analyst
- QA/Test Analyst

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Netlify Functions
- IBM watsonx Assistant (optional)

## Important Note

PathPilot provides career guidance, not a job guarantee. Role requirements and salary information should always be verified using current job listings.
